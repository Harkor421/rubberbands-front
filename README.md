## 📖 Sobre el proyecto

Sitio de una sola página del dispensador **Rubberbands & More** (versión ETH): cajón en vivo, cuenta regresiva de la próxima entrega, diagrama animado del mecanismo, feed de pagos y verificador de «tu puesto en la fila».

## ✨ Qué hace

- Verificador de tu posición en la fila de pagos
- Cajón y countdown en vivo por WebSocket
- Diagrama animado de cómo funciona
- Sin framework más allá de React: ni UI kit ni librería de estado
- Modo demo offline

## 🚀 Empezar

```bash
git clone https://github.com/Harkor421/rubberbands-front.git
cd rubberbands-front
npm install
npm run dev
```

## 📜 Scripts

| Comando | Qué hace |
|---|---|
| `npm run dev` | Servidor de desarrollo con recarga en caliente |
| `npm run build` | Compila para producción |
| `npm run start` | Arranca la aplicación |
